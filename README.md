# TenderApp Desktop — выпуски

Здесь публикуются установщики программы TenderApp для Windows. Исходный код здесь не хранится.

**Скачать:** откройте раздел [Releases](../../releases/latest) и скачайте `TenderApp-Setup-<версия>.exe`.

Установленная программа сама проверяет этот репозиторий и предлагает обновиться, когда выходит новая версия.

Нужна подписка [tenderapp.kz](https://tenderapp.kz).
